# Instruções do repositório

Antes de trabalhar neste repositório, leia e siga [.github/agent-instructions.md](.github/agent-instructions.md).

Esse arquivo centraliza os padrões definidos pelo usuário, incluindo a convenção obrigatória de commits no formato `tipo: descrição` (`feat: ...`, `fix: ...`, `docs: ...` etc.). Novos padrões devem ser documentados ali.
